## 1. 项目背景

当前要测试的是一条法币链路，参与方如下：

- 法币渠道：`Wewire`
- 上游聚合层：`PAY`
- 我方系统：`RB`

角色关系如下：

`Wewire -> PAY -> RB`

说明：

- `Wewire` 是法币渠道，提供 `VA`、`EUR 开户`、`入金`、`回调`能力。
- `PAY` 是 `RB` 的上游，负责承接 `RB` 请求、路由到 `Wewire`、管理订单、做回调转发、控制通道权限、提供下发 API。
- `RB` 是调用方，需要调用 `PAY` 完成开户、入金、下发等业务，并处理回调和对账。

## 2. 测试目标

需要验证以下内容：

1. `RB` 调用 `PAY` 完成 `VA` 相关流程。
2. `RB` 调用 `PAY` 完成 `EUR 开户`。
3. `RB` 调用 `PAY` 完成 `入金`。
4. `RB` 下单后，`PAY` 后台应生成对应订单。
5. `PAY` 后台路由配置生效。
6. `RB` 路由配置生效。
7. `PAY` 作为 `RB` 的上游，能够控制 `RB` 可以走哪些通道。
8. `PAY` 的下发 API 需要测试。
9. `PAY` / `RB` / `Wewire` 三方订单、状态、金额需要可对账。
10. 需要重点关注回调，包括成功回调、失败回调、重复回调、签名校验、幂等处理。

## 4. 业务规则

### 4.1 路由规则

- `RB` 发起请求后，请求会先到 `PAY`。
- `PAY` 根据后台路由配置决定是否将订单路由到 `Wewire`。
- `RB` 侧也可能存在自己的路由配置，需要验证其配置是否生效。
- 当 `PAY` 存在多条路由规则时，需要验证优先级是否正确。
- 路由配置变更后，需要验证是否即时生效，以及是否只影响新订单。

### 4.2 权限规则

- `PAY` 有权限控制 `RB` 可以走什么通道。
- 如果 `RB` 被授权走 `Wewire`，则相关业务应可以成功发起。
- 如果 `RB` 未被授权走 `Wewire`，则请求应失败，或返回明确的权限错误。
- 若按商户号、产品、币种进行权限控制，也需要覆盖测试。

### 4.3 `VA` / 开户规则

- `Wewire` 可以提供 `VA` 能力。
- `Wewire` 可以提供 `EUR 开户` 能力。
- `RB` 通过 `PAY` 发起请求后，`PAY` 应生成对应订单。
- 开户或 `VA` 成功后，`RB` 应能拿到正确结果。
- 需要验证参数缺失、参数非法、重复请求等情况。

### 4.4 入金规则

- `Wewire` 提供入金能力。
- 入金后，`PAY` 应接收渠道结果，并更新订单状态。
- `RB` 应通过回调或查询拿到最终结果。
- 需要验证成功、失败、处理中转成功、多笔入金等场景。

### 4.5 回调规则

- `Wewire` 或 `PAY` 会向 `RB` 发送回调。
- `RB` 需要校验回调签名。
- `RB` 需要处理重复回调，保证幂等。
- 需要验证成功回调、失败回调、重复回调、无效签名、回调乱序、回调重试。
- 如果 `RB` 首次响应失败，`PAY` 应按规则重推回调。

### 4.6 下发 API 规则

- `PAY` 提供下发 API。
- 需要验证有权限商户调用成功。
- 需要验证无权限商户调用失败。
- 需要验证参数合法性、幂等性、订单状态流转、回调结果。

### 4.7 对账规则

- `RB` 与 `PAY` 需要对账。
- `PAY` 与 `Wewire` 需要对账。
- 对账至少要覆盖订单数、成功金额、失败金额、处理中金额、手续费、净额。
- 需要覆盖差异单识别场景。
- 需要验证时间范围、币种、时区等维度。

## 5. 重点测试场景

生成测试用例时，请至少覆盖以下重点场景：

### 5.1 路由配置

- `PAY` 配置 `RB -> Wewire` 路由后，`RB` 下单命中 `Wewire`
- `PAY` 关闭 `Wewire` 通道后，`RB` 下单失败或切备用通道
- `RB` 自身路由配置切换后，请求按预期流转
- 多路由规则同时命中时，优先级正确
- 路由修改后，只影响新订单，不影响历史订单

### 5.2 权限控制

- `RB` 有 `Wewire` 权限时可以正常下单
- `RB` 无 `Wewire` 权限时下单失败
- `RB` 无某币种权限时请求失败
- 不同商户号权限不同的场景

### 5.3 `VA` / `EUR` 开户

- 创建 `VA` 成功
- `EUR` 开户成功
- 开户缺少必填参数
- 开户参数非法
- 重复业务单号请求

### 5.4 入金

- 入金成功
- 入金处理中后成功
- 入金失败
- 同一账户多笔入金
- 金额边界值场景

### 5.5 回调

- 成功回调处理成功
- 失败回调处理成功
- 重复回调幂等
- 签名错误回调被拒绝
- 回调乱序处理正确
- 首次回调失败后重推成功

### 5.6 下发 API

- 有权限商户下发成功
- 无权限商户下发失败
- 参数缺失或非法时报错
- 重复请求幂等

### 5.7 对账

- `RB` 与 `PAY` 对账一致
- `PAY` 与 `Wewire` 对账一致
- 差异单可以识别
- 跨日、时区、时间范围统计正确
